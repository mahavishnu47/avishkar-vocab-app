# Appendix: every action each user can perform

Use this as a checklist. "Where" tells you which screen to open. The guides above explain each action in more detail.

## A. Student actions

| # | Action | Where | How |
|---|---|---|---|
| S1 | Open the app from the class link | Phone browser | Open `/j/CLASSCODE` or scan the QR on the PIN card |
| S2 | Open the app from the school link | Phone browser | Open `/s/SCHOOLCODE`, pick your class, then your name |
| S3 | Log in with a class code | Home page, **I'm a Student** | Type the 6-character class code, pick your name, type your PIN |
| S4 | Type my PIN | PIN pad | Tap the 4 digits. Wrong PIN: try again. Too many wrong tries locks the profile for a short time |
| S5 | Recover a forgotten PIN | **Forgot PIN** | Ask your teacher for a new PIN card |
| S6 | Ask to join a class | **I'm not on the list** | Type your first name. The teacher approves. The app shows your PIN after approval |
| S7 | Watch the welcome | After first login | About 30 seconds, then **Let's play** |
| S8 | Play the daily five words | **Play** | For each word: hear it, spell it, choose the meaning, choose the kind of word, write a sentence |
| S9 | Hear a word or question | Speaker buttons | Normal speed or slow. Read-aloud for questions |
| S10 | Get a hint | During spelling or sentence | Use the hint button or **Help me start** |
| S11 | See my day's result | **Summary** after the words | Word marks and XP earned |
| S12 | Do the recall challenge | Home card before the words | Answer quick questions on yesterday's and older words |
| S13 | Open My Word Bank | Home | Search words, filter by kind of word, hear a word, see my best sentence and stars |
| S14 | See my progress | Level button on Home | Words learned, last 14 days, skills, words to practise, last days |
| S15 | See the leaderboard | Trophy button | This week's ranking (if the teacher allows it) |
| S16 | Take a word test | **Test** | Type the 4-letter code from the board, answer, **Check your answers** |
| S17 | Answer the feedback questions | Home card **Tell us what you think** | Yes / To some extent / No, when the teacher opens it |
| S18 | Switch player on a shared phone | **Who's playing?** or **Switch player** | Tap your face. Another child's profile needs that child's PIN |
| S19 | Remove a profile from the phone | **Who's playing?** | Needs that child's PIN |
| S20 | Log out | **Log out** on Home | Confirm **Yes, log out** |
| S21 | Put the app on the home screen | Install prompt | Tap **Put WordWise on your home screen** |
| S22 | Update the app | Banner | When it says **A new version is ready.**, tap **Refresh** |
| S23 | Use it with weak internet | Automatic | Saved info shows and work syncs later |

A student **cannot**: see another child's progress, open or delete another child's profile without the PIN, change their words, or see their test marks.

## B. Teacher actions

| # | Action | Where | How |
|---|---|---|---|
| T1 | Join the school | `/t/CODE` or `/teacher/join` | Name, email, password, **Join school** |
| T2 | Log in | `/teacher` | Email and password |
| T3 | Reset my password | Link from the principal | Open `/r/CODE`, choose a new password |
| T4 | Follow the starter checklist | Home, **What to do next** | Tap the highlighted **Next** step |
| T5 | Create a class | Home, **Create your class** | Pick standard and division, **Create class** |
| T6 | Add children | Class, **Add students** | Paste or upload a list, check the preview, tick consent, **Save** |
| T7 | Print login cards | Class, **Print login cards** | Print, cut, give each child their card |
| T8 | Share the class link | Share, **Send on WhatsApp** | Send the link to parents |
| T9 | Show or print the QR code | Share, **Show on screen** | Display it on the board |
| T10 | Stop or allow joining with the link | Share, **Students can join with this link** | Switch off or on |
| T11 | Make a new class link | Share, **Make a new link** | Old link stops working |
| T12 | See who is in the class | **Roster** | Names, avatars, status, last play |
| T13 | Approve or remove join requests | Roster, **Waiting to join** | **Approve** or **Remove** |
| T14 | Reset a child's PIN | Roster or child page, **Reset PIN** | Give the child the new PIN. It signs out other phones |
| T15 | Rename, renumber or turn off a child | Roster | Edit and save, or deactivate |
| T16 | Check today | **Dashboard** | Joined, played, finished, not started |
| T17 | Choose a day's words | **Words** | Word picker, custom word, **Save day**, **Reset to auto** |
| T18 | Add a custom word | Words, **Custom word** | Word, meaning, difficulty, example, **Add word** |
| T19 | Show or hide the leaderboard | **Leaderboard**, **Show leaderboard to students** | Toggle. View **This week** or **All time** |
| T20 | See class analytics | **Analytics** | Choose **From** and **To**. See **Hardest words** |
| T21 | See one child's detail | Tap the child | Strength, needs support, spelling errors, sentence marks, sessions |
| T22 | Print the assignment record | **Progress**, **Print record** | Days by children grid. Can show study codes |
| T23 | Create a study | **Study**, **Create study** | Name, start date, school days (default 10) |
| T24 | Put classes in the study | Study page | Add as **Intervention** or **Comparison** |
| T25 | Record consent | **Students and consent** | given, declined, withdrawn, excluded |
| T26 | Print the code sheet | Study, **Print code sheet** | Study codes against names. Keep it private |
| T27 | Manage the word plan | **Words plan** | See 10 days, add **Holiday**, swap words, **Print the list** |
| T28 | Run the pre-test and post-test | Class, **Tests** | Create, **Open test**, write the code, **Close test** |
| T29 | Print a paper test | Tests, **Print form A** or **Print form B** | Give out, then **Save paper marks** |
| T30 | Review and change marks | Tests, a child | Auto marks, **Final marks**, marking scheme |
| T31 | Check sentences for copying | **Sentence check** | Mark each **Own work** or **Not own work** |
| T32 | Record weekly observations | **Instruments**, **Weekly observation** | Pick the week, tap Yes or No for six points |
| T33 | Run the student questionnaire | Instruments | Open it, children answer, add paper answers, **Close questionnaire** |
| T34 | Read the results | **Results** | Gains, p-value, charts, comparison, participation |
| T35 | Export | Results | **Download research pack** (CSV) or **Print or save as PDF** |
| T36 | Delete a child's research data | Study, **Delete research data** | Confirm. Used for withdrawals |
| T37 | Close the study | Study status | Set to **closed** |

A teacher **cannot**: see other teachers' classes (unless a school admin), see another school, or see children's research data under names in exports.

## C. Principal (school admin) actions

| # | Action | Where | How |
|---|---|---|---|
| P1 | Create the school account | Setup link `/a/CODE` | Name, email, password, **Create my account** |
| P2 | Log in | `/school` | Email and password |
| P3 | Follow the Getting started checklist | Progress | Ticks itself |
| P4 | Invite teachers | Progress or **Teachers**, **WhatsApp** | Send the teacher link and school code |
| P5 | Make a new teacher code | Teachers, **New code** | Old code stops working |
| P6 | Stop new teachers joining | Teachers, **Turn off code** | Make a code again to reopen |
| P7 | Reset a teacher's password | Teachers, **Reset password** | Send the one-time link (24 hours) |
| P8 | Turn a teacher off or on | Teachers | **Turn off**, **Turn on** |
| P9 | Make or remove an admin | Teachers | **Make admin**, **Remove admin**. Keep at least one admin |
| P10 | Watch all classes | **Progress** | Teacher, students, joined, played today, this week |
| P11 | See top classes | Progress | **Top classes this week** |
| P12 | See, move or archive classes | **Classes** | Change teacher, **Archive**. See whether joining is On or Off |
| P13 | Edit the school details | **Settings** | School name and district |
| P14 | Share the student link | Settings, **Student link** | Children pick class and name |
| P15 | Make a new student link | Settings, **New link** | Confirm **Yes, make a new link**. The old one stops |
| P16 | Print the poster | Settings, **Print poster** | QR code for the notice board |
| P17 | Read recent activity | Settings, **Recent activity** | Who did what, such as PIN resets |
| P18 | See studies and consent counts | School pages | Read-only view of studies in the school |
| P19 | Log out | **Log out** button | Ends the session |

A principal **cannot**: remove the last admin, see another school, or reset their own password (ask WordWise for a new setup link).
